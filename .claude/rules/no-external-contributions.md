# No contributions to external projects

Never suggest, let alone open, PRs, issues or patches against third-party projects: plugin repos, dependencies, SICK's SDK, upstreams. Extend or fix external tooling for this repo's needs locally, through a mirror, a wrapper or a fork-in-repo. Never upstream.

**Why:** carried over from the operator's time-keep repo (2026-10-30). The operator does not want to contribute to large external projects and does not want it suggested.

**How to apply:** when external tooling falls short, present only local options. The word "upstream" should not appear in a proposal.
